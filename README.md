# AI 自动阅卷助手

基于 Electron 的智能阅卷批改桌面软件。截图识别学生作答，由 AI 按自定义评分标准自动给分、填分、提交，支持分小题拆分给分与双评仲裁，把重复性的阅卷操作交给机器。

当前版本：**1.1.0**（Windows / macOS）

---

## 核心特性

### 识别与评分

- **三种评分来源**
  - 云端网络评分：内置 12 家主流 AI 厂商（智谱、豆包/火山方舟、通义千问、DeepSeek、OpenAI、Kimi、讯飞、腾讯混元、月之暗面、硅基流动等），支持任意 OpenAI 协议第三方中转接口
  - 本机本地评分：Ollama、LM Studio
  - 局域网分布式评分：多节点负载均衡、健康检查
- **三种识别评分工作流**
  - 多模态直评：答题区域截图直接交视觉模型评分（推荐）
  - 本机 OCR 二次评分：本地模型先识别文字，再由评分模型评分
  - 云端 OCR 二次评分：云端 OCR 模型识别后再评分
- **AI 一键定位**：自动截屏识别并定位答题区域、分数输入框（整题或分小题）、提交按钮；识别到多个分数输入框时自动创建分小题，分值按总分自动均分；定位框在屏幕上叠加显示，可拖动移动、拖角调整大小后确认保存

### 批改模式

| 模式 | 行为 |
|---|---|
| 普通模式 | 评分完成 5 秒倒计时自动提交 |
| 试改模式 | 评分完成后人工确认再提交 |
| 无人值守模式 | 评分完成立即提交，全自动连续批改 |
| 双评模式 | 双模型独立评分取平均，分差超阈值转人工仲裁；仲裁带历史偏向学习（某模型领先 ≥2 票时建议值直接取该模型分数），5 秒自动提交 |

### 稳定性保障

- **翻页检测**：截图哈希比对判断页面是否翻页；未翻页 5 秒倒计时后自动重评；连续 3 次未翻页自动暂停，防止死循环
- **空白卷识别**：按墨迹占比识别空白卷，跳过同题判定照常评分提交（连续 30 份空白卷暂停防呆）
- **全链路日志**：每题识别结果、评分过程、最终得分、点击填分截图全程留存（日志与截图存档 30 天自动清理）
- **分小题批量填分**：多小题分值一次性紧凑填充（约 0.3 秒/框），剪贴板只保存恢复一次

### 评分标准管理

- 最多 **10 套评分标准预设**循环切换，下拉选择即启用，批改时侧边栏 ‹ › 快速换套
- 五个独立子页：评分标准 / 题目题干 / 参考答案 / 作答要求 / 示例参考
- **Markdown + LaTeX 实时渲染预览**（行内 `$x^2$`、独立 `$$\int x\,dx$$`）
- **粘贴截图自动识别**：窗口内任意位置 Ctrl+V，文字自动转 Markdown/LaTeX，几何图形等无法转录的内容以原图嵌入预览；多模态模式下嵌入的题干图形会作为参考图片随评分请求发送
- AI 自动生成评分细则（按题干/答案生成分档标准）
- 示例参考支持导入本地图片，评分时作为参考图附给视觉模型

### 界面与交互

- **悬浮侧边栏**：可拖拽、一键隐藏/呼出，不占用阅卷系统窗口空间
- 全局快捷键 `Ctrl+Shift+G` 呼出/隐藏；托盘图标双击呼出
- 首次使用引导，非技术用户可快速上手
- 所有配置本地持久化，重启不丢失

## 快速开始

### 环境要求

- Node.js ≥ 18
- npm ≥ 9
- Windows 10/11 或 macOS 12+

### 开发调试

```bash
npm install        # 安装依赖
npm run dev        # 启动开发模式（electron-vite）
```

### 打包

```bash
npm run build:win  # 构建 Windows 安装包（输出 release/AI自动阅卷助手 Setup x.x.x.exe）
npm run build:mac  # 构建 macOS 安装包
npm run build      # 仅编译产物，不打包
```

## 使用流程

1. **配置 AI 服务**：设置 → 模型与规则 → 评分与识别模型，添加并测试 AI 服务商（或配置 Ollama / LM Studio / 局域网节点），选择识别评分模式（多模态直评推荐）
2. **设置分值**：设置 → 答题区域与分值 → 分值配置，填写题目总分
3. **标记区域**：同页答题区域分区，一键 AI 定位（或手动框选）；多个分数输入框会自动分小题并均分分值；屏上核对调整后确认
4. **编写评分标准**：设置 → 评分标准管理，粘贴题干/答案截图自动识别，编写评分细则
5. **选择批改模式**：主页 → 批改模式（普通 / 试改 / 无人值守 / 双评）
6. **开始批改**：在阅卷系统（如智学网）中进入批改界面，点击「开始批改」，软件自动截图 → AI 评分 → 填分 → 提交 → 等待翻页 → 下一题
7. **暂停/继续**：随时暂停；未翻页暂停时点「继续」会对当前题重新执行完整批改流程

## 项目结构

```
src/
├── main/                  # Electron 主进程
│   ├── ai/                # AI 服务商注册、调用、负载均衡、一键定位
│   ├── grading/           # 批改状态机、提示词构建、管道、截图哈希/空白卷检测
│   ├── ipc/               # IPC 通道注册
│   ├── services/          # 配置存储、日志、屏幕自动化（截屏/点击/填分）
│   ├── windows/           # 侧边栏、设置窗口、定位框调整层
│   └── index.ts           # 入口：托盘、快捷键、单实例锁、stdimg 协议
├── preload/               # 预加载脚本（contextBridge 暴露安全 API）
├── renderer/
│   ├── sidebar/           # 悬浮侧边栏（批改控制、状态展示）
│   ├── settings/          # 设置界面（模型与规则、答题区域与分值、评分标准等）
│   ├── overlay/           # 定位框调整层
│   └── components/        # Markdown/LaTeX 渲染等公共组件
└── shared/                # 主/渲染进程共享类型与 IPC 契约
```

## 技术栈

- **Electron 44** + electron-vite 5
- **React 18** + TypeScript
- **Ant Design 5**（界面组件）
- **react-markdown + remark-math + rehype-katex**（公式渲染）
- **electron-builder**（打包分发）

## 数据存储

- 用户数据目录（Windows：`%APPDATA%\AI自动阅卷助手`；macOS：`~/Library/Application Support/AI自动阅卷助手`）
  - `config.json`：全部配置（服务商、区域标记、评分标准、批改参数）
  - `standards/`：评分标准嵌入图与示例参考图
  - `logs/`：运行日志与批改截图存档（30 天自动清理）
