# AI 自动阅卷助手

基于 Electron 的智能阅卷批改桌面软件。截图识别学生作答，由 AI 按自定义评分标准自动给分、填分、提交，支持分小题拆分给分与双评仲裁，把重复性的阅卷操作交给机器。

当前版本：**1.3.0**（Windows / macOS）

### 1.3.0 更新说明

- 评分标准精简为「题目题干 → 参考答案 → 评分标准」三个字段，移除作答要求、示例参考及名称/年段/学科/题型输入框；页面说明同步精简
- 三个字段改为点击内容区直接打开**屏幕居中的独立富文本编辑窗口**（可视化 / 源码 / 预览三模式），不再有编辑按钮
- 「AI 生成评分标准」按钮移到评分标准卡片旁，一键生成结果直接写入该字段，移除顶部生成弹窗
- 编辑器支持**右键粘贴**：文本直接粘贴，截图可选「仅粘贴图片」或「AI 识别截图并粘贴（仅文字，不附原图）」；Ctrl+V、拖入图片行为同步调整
- 分值配置移除最低分 / 最高分输入框，打分范围固定为 0～总分
- AI 识别粘贴后只插入转写文字，内容末尾不再显示截图（识别失败或无文字时才回退插入原图）
- 移除首次使用引导、整屏设置菜单列表，以及齿轮与托盘的「打开设置」入口；设置项统一由主界面「前期设置」四个按钮直达
- 「通用设置」移到主页阅卷统计下方，可收缩且默认收起，收纳预设方案、批改日志、导入/导出配置、全局快捷键、重启与退出
- 小题较多时，主界面「最近一题」与纠错弹窗中的小题得分、教师改分改为自适应多列网格（自动换行），不再逐行纵向铺开，显著减少占用高度

## 核心特性

### 识别与评分

- **三种评分来源**
  - 云端网络评分：内置 12 家主流 AI 厂商（智谱、豆包/火山方舟、通义千问、DeepSeek、OpenAI、Kimi、讯飞、腾讯混元、月之暗面、硅基流动等），支持任意 OpenAI 协议第三方中转接口
  - 本机本地评分：Ollama、LM Studio
  - 局域网分布式评分：多节点负载均衡、健康检查
- **三种识别评分工作流**
  - 多模态直评：答题区域截图直接交视觉模型评分（推荐）
  - 本机 OCR 二次评分：本地模型先识别文字，再由评分模型评分
  - 云端 OCR 二次评分：云端 OCR 模型识别后再评分
- **AI 一键定位**：自动截屏识别并定位答题区域、分数输入框（整题或分小题）、提交按钮；识别到多个分数输入框时自动创建分小题，分值按总分自动均分；定位框在屏幕上叠加显示，可拖动移动、拖角调整大小后确认保存

### 批改模式

| 模式 | 行为 |
|---|---|
| 试改模式 | 每份评分后自动弹出纠错窗口，核对/纠错后确认提交 |
| 无人值守模式 | 评分完成立即提交，全自动连续批改 |
| 双评模式 | 双模型独立评分取平均，分差超阈值转人工仲裁；仲裁带历史偏向学习（某模型领先 ≥2 票时建议值直接取该模型分数），5 秒自动提交 |

### AI 评分纠错（试改模式）

- 试改模式每份评分完成后**自动弹出纠错窗口**，提交确认按钮集成在窗口内，核对无误一键提交
- **教师改分**：整题改分或分小题独立修正，小题分自动求和为总分，也可手动覆盖总分；教师给出的分数只做越界夹取，**绝不按步长静默改写**
- **评分理由**：支持 Markdown 编辑与实时预览，可交 AI 润色后提交
- **两步纠错**：第一步提交教师反馈后，第二步 AI 流式分析判分差异，给出评分标准优化建议；教师审核确认后自动更新当前评分标准的参考答案/评分标准
- **分数精度**：AI 给分按打分步长精确归一化对齐（支持 1.5、0.25 等任意小数步长），消除浮点误差

### 稳定性保障

- **翻页检测**：截图哈希比对判断页面是否翻页；未翻页 5 秒倒计时后自动重评；连续 3 次未翻页自动暂停，防止死循环
- **空白卷识别**：按墨迹占比识别空白卷，跳过同题判定照常评分提交（连续 30 份空白卷暂停防呆）
- **全链路日志**：每题识别结果、评分过程、最终得分、点击填分截图全程留存（日志与截图存档 30 天自动清理）
- **分小题批量填分**：多小题分值一次性紧凑填充（约 0.3 秒/框），剪贴板只保存恢复一次

### 评分标准管理

- 最多 **10 套评分标准预设**循环切换，下拉选择即启用，批改时侧边栏 ‹ › 快速换套
- 三个字段按「题目题干 → 参考答案 → 评分标准」顺序排列，任意一项有内容即可批改
- **独立富文本编辑窗口**：点击字段内容区即在屏幕中央打开独立窗口（不受侧边栏尺寸限制），可视化 / 源码 / 预览三种模式，标题、粗斜体、删除线、列表、任务列表、引用、代码、表格、链接、图片、LaTeX 公式、分割线、清除格式、撤销重做一应俱全，支持快捷键；保存后自动回填对应字段
- **Markdown + LaTeX + GFM 实时渲染预览**（行内 `$x^2$`、独立 `$$\int x\,dx$$`、表格与任务列表）
- **粘贴截图**：窗口内 Ctrl+V 或右键「AI 识别截图并粘贴」自动把截图转写为 Markdown/LaTeX 文字，**只插入识别文字、内容末尾不再附原图**（识别失败或无文字时才回退插入原图）；右键「仅粘贴图片」、拖入图片、导入本地图片则只插入原图；文本直接粘贴。多模态模式下嵌入的原图会随评分请求发送（最多 3 张）
- **AI 生成评分标准**：点击「评分标准」卡片上的按钮，即依据当前套已输入的题目题干与参考答案生成分档、分值闭合的评分标准，结果直接写入该字段（已有内容时先确认覆盖），再点击字段内容区即可润色

### 界面与交互

- **悬浮侧边栏**：可拖拽、一键隐藏/呼出，不占用阅卷系统窗口空间
- 全局快捷键 `Ctrl+Shift+G` 呼出/隐藏；托盘图标双击呼出
- **前期设置**：主界面四个入口直达 AI 服务商、模型与规则、评分标准、答题区域
- **通用设置**：位于阅卷统计下方、默认收起，收纳预设方案、批改日志、导入/导出配置、全局快捷键、重启与退出
- 所有配置本地持久化，重启不丢失

## 使用流程

1. **配置 AI 服务**：主界面「前期设置」→「AI 服务商」/「模型与规则」，添加并测试服务商（或配置 Ollama / LM Studio / 局域网节点），选择识别评分模式（多模态直评推荐）
2. **设置分值／编写评分标准**：主界面「前期设置」→「评分标准」，填写题目总分与打分步长（打分范围固定为 0～总分）；点击字段内容区在独立编辑窗口中填写题目题干与参考答案（可粘贴截图自动识别），再点击「评分标准」卡片上的「AI 生成」一键起草并写入该字段，任意字段有内容即可开始批改
3. **标记区域**：主界面「前期设置」→「答题区域」，一键 AI 定位（或手动框选）；多个分数输入框会自动分小题并均分分值；屏上核对调整后确认
4. **选择批改模式**：主页 → 批改模式（普通 / 试改 / 无人值守 / 双评）
5. **开始批改**：在阅卷系统（如智学网）中进入批改界面，点击「开始批改」，软件自动截图 → AI 评分 → 填分 → 提交 → 等待翻页 → 下一题
7. **暂停/继续**：随时暂停；未翻页暂停时点「继续」会对当前题重新执行完整批改流程

## 项目结构

```
src/
├── main/                  # Electron 主进程
│   ├── ai/                # AI 服务商注册、调用、负载均衡、一键定位
│   ├── grading/           # 批改状态机、提示词构建、管道、截图哈希/空白卷检测
│   ├── ipc/               # IPC 通道注册
│   ├── services/          # 配置存储、日志、屏幕自动化（截屏/点击/填分）
│   ├── windows/           # 侧边栏、设置窗口、定位框调整层
│   └── index.ts           # 入口：托盘、快捷键、单实例锁、stdimg 协议
├── preload/               # 预加载脚本（contextBridge 暴露安全 API）
├── renderer/
│   ├── sidebar/           # 悬浮侧边栏（批改控制、状态展示）
│   ├── settings/          # 设置界面（模型与规则、答题区域与分值、评分标准等）
│   ├── correction/         # AI 纠错窗口（试改核对、教师改分、评分标准优化）
│   ├── richtext/           # 屏幕居中的独立富文本编辑窗口
│   ├── overlay/           # 定位框调整层
│   └── components/        # Markdown/LaTeX 渲染等公共组件
└── shared/                # 主/渲染进程共享类型与 IPC 契约
```

## 技术栈

- **Electron 44** + electron-vite 5
- **React 18** + TypeScript
- **Ant Design 5**（界面组件）
- **react-markdown + remark-math + rehype-katex**（公式渲染）
- **electron-builder**（打包分发）

## 数据存储

- 用户数据目录（Windows：`%APPDATA%\AI自动阅卷助手`；macOS：`~/Library/Application Support/AI自动阅卷助手`）
  - `config.json`：全部配置（服务商、区域标记、评分标准、批改参数）
  - `standards/`：题目题干 / 参考答案 / 评分标准中嵌入的原图
  - `logs/`：运行日志与批改截图存档（30 天自动清理）
